# Support

Start with the [Saggar documentation](https://saggar.marginalutility.dev/docs) and [troubleshooting guide](https://saggar.marginalutility.dev/docs/help/troubleshooting).

If that doesn't resolve the problem:

- Use [Discussions](https://github.com/mcclowes/saggar/discussions) for questions and setup help.
- Use the [bug report form](https://github.com/mcclowes/saggar/issues/new?template=bug.yml) for reproducible product defects.
- Follow [SECURITY.md](SECURITY.md) for vulnerabilities.

Saggar is maintained by a small team. Clear reports with a minimal reproduction are much easier to act on.
